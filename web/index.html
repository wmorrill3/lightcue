How it works

  1. It listens. Tempo, every kick and hi-hat, the build-ups and the drops, mapped onto the car's 50 frames per second.
  2. It choreographs. Headlight chases on the hats, brake hits on the kick, a blackout before the drop. Then the liftgate opens, the windows dance and the charge port flashes rainbow on the big moment. Every Tesla limit is respected.
  3. You plug it in. Copy the pack to a USB drive and open Toybox. The light show, a lock sound cut from the hook and your wrap are ready.

Works on Model 3, Model Y, Model S (2021+), Model X (2021+) and Cybertruck, software 11.0 or newer. Shows pass Tesla's own validator before you download them.

Fleet

Two cars or twelve. One show.

Set the number of cars and LightCue writes a different part for each one. Chases run from car to car, the hits land together, and each interior gets its own colour. Park them in order, schedule the same start time in each car and they play as one.

For car meets, weddings, launches and dealer events.

For agents

An API and an MCP server, so any AI can do this.

Claude, ChatGPT or your own agent can make a show for its user: send a song link and get back a validated USB pack. Four tools: list_options, create_light_show, get_light_show, validate_fseq. The whole engine is open source on GitHub (MIT), so you can also run it yourself.

{
  "mcpServers": {
    "lightcue": { "url": "/mcp" }
  }
}
curl -X POST "/api/v1/shows?car=modely&vibe=party" \
  -H "content-type: audio/mpeg" --data-binary @song.mp3

# → { "id": "…", "status": "queued" }
curl /api/v1/shows/<id>
# → status "done", download, preview, analysis

Good to know

Is it safe for my car?
Shows use Tesla's official light show format. Every closure stays inside Tesla's per-show command limits, dances are kept under 30 seconds, and on Model X the windows never move while the falcon doors do. You can also pick "Lights only".
How do I play it?
Format a USB drive as exFAT or FAT32, copy the pack to the root, plug it in and go to Toybox → Light Show. Park somewhere with room around the car.
Does it work on the new Roadster?
Not in the car yet: the Roadster ships in 2027 and Tesla hasn't published its light-show format. Pick Roadster to watch your show with liftoff on the drop and record the clip. Join the list and you'll get the real file the day Tesla opens it.
What happens to my song?
It's used to make your show and deleted after processing. The preview audio and your pack expire after 7 days.
